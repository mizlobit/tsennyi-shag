# Ценный шаг

Готовый статический сайт. Установка зависимостей и сборка не нужны.

1. Распакуйте архив.
2. Загрузите index.html, style.css, app.js и папку assets в корень репозитория или папку tsennyi-shag существующего сайта.
3. В Settings → Pages выберите Deploy from a branch, ветку main, / (root). Для уже работающего Pages сохраните текущие настройки.
4. Дождитесь публикации.

Для репозитория USERNAME.github.io и папки tsennyi-shag адрес: https://USERNAME.github.io/tsennyi-shag/

Сохраняйте структуру папок. На компьютере сайт можно посмотреть, открыв index.html.
